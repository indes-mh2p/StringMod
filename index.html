Export writes N = highest ID + 1. IDs missing from the table become empty strings with flag 0. Changed rows are marked on the left edge; duplicate IDs are shown in red and block export.
File format reference 
uint32 BE      N            number of string IDs
uint32 BE[N+1] offset[]     start of string i in the text blob; offset[N] = blob length
bytes          blob         UTF-8 strings back-to-back, no terminators (length = offset[i+1] - offset[i])
uint8[N]       flag[]       per-ID status byte: 8 = translated, 0 = empty/untranslated, 2 = other
